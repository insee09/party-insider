วิธีเล่น Insider Game สรุปย่อ

🎭 1. บทบาทในเกม:
  • Game Master (GM): รู้คำศัพท์ คอยตอบคำถาม "ใช่ / ไม่ใช่ / ไม่เกี่ยวข้อง"
  • Insider: แอบรู้คำศัพท์ ต้องเนียนช่วยแนะแนวทางโดยไม่ให้ใครสงสัย
  • Common: ไม่รู้คำศัพท์ ต้องช่วยกันถามคำถามเพื่อทายคำศัพท์ให้ถูก
⏱️ 2. ขั้นตอนการเล่น:
  1. เปิดเวลานับถอยหลัง 2-5 นาที ทุกคนช่วยกันถาม GM เพื่อทายคำศัพท์
  2. เมื่อมีคนทายคำศัพท์ถูก เวลาจะหยุดลง
  3. หากไม่มีใครทายคำถูกจนหมดเวลา จะถือว่าทุกคนแพ้
  4. สลับเข้าสู่ช่วง **"โหวตจับ Insider"** ทุกคนอภิปรายว่าใครเนียนชี้ชวน แล้วกดโหวต
  5. หากโหวตจับ Insider ถูกต้อง ➔ ฝั่ง Common ได้คะแนน / หากจับผิด ➔ Insider ได้คะแนนคนเดียว
